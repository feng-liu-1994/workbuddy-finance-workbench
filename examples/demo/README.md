# 虚构演示数据

这里的单位、账号、交易和金额均为虚构，只用于练习“银行流水与账务明细核对”。

建议任务：

```text
使用 finance-workbench 核对 银行流水_示例.csv 与 账务明细_示例.csv。
先统一日期、方向、金额和摘要字段；唯一匹配优先；不能确定的进入疑似匹配；输出已匹配、未匹配、差异原因和金额校验。不要修改源文件。
```

预期观察：

- `DEMO-001`、`DEMO-002`、`DEMO-003` 可以唯一匹配。
- 银行流水中的 `DEMO-004` 没有对应账务记录。
- 账务明细中的 `DEMO-005` 没有对应银行流水。
- 两边应分别保留输入金额合计和差额，不能为了平衡而强行匹配。
