# 25 个财务工作流提示词

每份提示词都可直接复制到 WorkBuddy、Codex、Claude Code 或其他支持文件处理的 AI 工具。新手填写区不清楚的项可留空，AI 会先识别现有资料并一次列出必需缺项。

- [01 · Excel 原始数据自动清洗](01-excel-cleaning.md) — 输出字段统一、格式规范、异常单列的标准数据表。
- [02 · 多张 Excel 批量合并](02-excel-merge.md) — 批量合并为统一明细表，并输出来源、缺失字段和重复记录。
- [03 · 费用报销自动汇总](03-expense-summary.md) — 生成部门、项目、费用类型汇总及异常报销清单。
- [04 · 重复报销与异常费用检查](04-expense-duplicate-check.md) — 按多条件识别完全重复和疑似重复，形成分级复核清单。
- [05 · 银行流水与账务明细核对](05-bank-reconcile.md) — 生成已匹配、疑似匹配、未匹配和差异原因清单。
- [06 · 订单、回款、发票三表核对](06-order-cash-invoice.md) — 形成订单-回款-发票三方勾稽表及差异跟进清单。
- [07 · 应收账款账龄分析](07-ar-aging.md) — 生成客户账龄分布、逾期金额、重点风险和催收建议。
- [08 · 应付账款到期与付款排期](08-ap-schedule.md) — 生成到期付款计划、资料缺失清单和资金压力提醒。
- [09 · 发票台账自动整理](09-invoice-ledger.md) — 识别票面信息并生成标准发票台账、缺失字段和疑似重复清单。
- [10 · 发票与付款记录匹配](10-invoice-payment-match.md) — 形成发票-付款对应关系及未付款、超付款和待确认清单。
- [11 · 进项与销项发票月度核对](11-vat-monthly-check.md) — 形成进销项汇总、税率分布、异常状态和申报前待确认事项。
- [12 · 固定资产台账更新与折旧检查](12-fixed-assets.md) — 更新固定资产台账并输出新增、变动、折旧和异常清单。
- [13 · 库存进销存差异检查](13-inventory-check.md) — 生成数量、金额、负库存、异常出入库和待查原因清单。
- [14 · 工资、社保、个税三表核对](14-payroll-check.md) — 生成员工级差异表及新增、离职、基数和金额异常清单。
- [15 · 月末结账资料完整性检查](15-month-close-completeness.md) — 生成月结任务完成表、缺失资料、异常差异和责任人清单。
- [16 · 月度经营报表自动生成](16-monthly-management-report.md) — 生成标准经营报表、同比环比分析和异常变化说明。
- [17 · 预算执行与偏差分析](17-budget-variance.md) — 生成预算达成、超支、节余、趋势和纠偏行动表。
- [18 · 部门费用与降本分析](18-cost-reduction.md) — 生成费用结构、增长贡献、异常项目和可验证的降本清单。
- [19 · 现金流与资金预测](19-cashflow-forecast.md) — 生成滚动现金流预测、资金缺口和关键假设提醒。
- [20 · 老板汇报表与管理摘要](20-management-summary.md) — 把经营数据整理成结论、风险、原因和需要决策的事项。
- [21 · 全表异常数据自动检查](21-full-table-anomaly.md) — 形成通用异常检查报告，帮助财务优先复核高风险记录。
- [22 · 凭证附件与财务文件归档](22-voucher-archive.md) — 按统一规则整理目录、命名清单和缺失附件报告。
- [23 · 合同付款条款提取](23-contract-terms.md) — 定位条款原文，形成合同主表、付款计划与到期风险清单。
- [24 · 周期任务与本地自动化](24-local-automation.md) — 把月结、付款到期和周报做成可试运行、可追溯的本地任务。
- [25 · 财务制度知识库与受控协同](25-policy-knowledge.md) — 整理制度证据库，生成有出处的问答与权限清晰的协同流程。
