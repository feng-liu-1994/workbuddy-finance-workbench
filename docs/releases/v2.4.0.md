# v2.4.0 · WorkBuddy 完整可视化应用

本版本把 WorkBuddy 支持从“仅安装 Skill”升级为可直接打开的完整 MCP App，并重做全部新手安装与项目首页说明。

## 新增

- WorkBuddy MCP App：20 个模块、25 个工作流、异常控制、月结、资料索引和本机备份。
- `show_finance_workbench` 工具与 `text/html;profile=mcp-app` UI 资源。
- macOS 双击安装包、Windows PowerShell 安装包、源码安装与可恢复卸载。
- MCP 协议、Widget 体积、隔离安装、配置保留和公开发布完整性测试。

## 安装

- macOS 下载 `workbuddy-finance-workbench-macos.zip`，解压并双击安装文件。
- Windows 下载 `workbuddy-finance-workbench-windows.zip`，执行包内 PowerShell 安装器。
- DeepSeek Harness 用户继续使用 `dsh-finance-workbench-2.4.0.tgz` 或源码安装脚本。
- 只需要规则库的 AI Agent 可使用 `finance-workbench-agent-v2.4.0.zip`。

安装后保存当前内容，完全退出并重新打开 WorkBuddy，输入“打开财务工作台”。安装器不会主动重启应用。
