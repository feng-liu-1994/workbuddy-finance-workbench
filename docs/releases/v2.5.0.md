# v2.5.0 · 新手可见的 25 份提示词

本版本把原本藏在数据源和运行时文件中的工作流提示词，变成财务人员可直接看懂、查看和复制的公开能力。

## 主要升级

- 25 个工作流统一编号 01–25，每个场景都有一份独立 Markdown 提示词。
- 工作台详情页显示“最少先准备什么”、一句话发起和新手三步路径。
- 完整提示词可展开预览、一键复制；剪贴板不可用时会下载文本文件。
- 提示词允许新手对不清楚的主体、期间或口径留空，由 AI 先识别现有资料并一次列出必需缺项。

## 保留能力

资料上传、文件夹导入、拖放、搜索、筛选、置顶、引用、下载、异常闭环、待办、月结、审计日志、备份恢复和 4 套主题均保留。
