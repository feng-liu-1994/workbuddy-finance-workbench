# WorkBuddy 财务工作台 v2.2.0

这是一次以“更高级、更现代、更好用”为目标的界面与内容升级。新版吸收现代业务工作台的雾光层次、聚焦式标题和清晰导航，同时保持财务产品应有的克制、专业和信息密度。

## 本版亮点

- 4 套主题：雾光靛蓝、松石墨绿、暖砂棕金和夜航深色；支持快速切换、刷新保留和备份恢复。
- 今日财务节奏：首页集中提示高优先级待办、月结证据进度和经营数据完整度。
- 新手工作指引：15 个业务模块都补充责任岗位、建议频率和第一步操作，不必先理解整套系统。
- 现代响应式界面：桌面、窄窗口和手机均保持清晰层级，无横向溢出。
- 能力完整保留：资料上传、文件夹导入、拖放、搜索、筛选、置顶、引用、下载、待办、月结、审计和 25 个 AI 工作流均保留。

截图中的名称、金额和业务内容均为虚构演示数据。

## 下载哪个文件

- `finance-workbench-agent-v2.2.0.zip`：WorkBuddy、Codex、Claude Code 或其他支持 Skill 的 AI Agent。
- `dsh-finance-workbench-2.2.0.tgz`：DeepSeek Harness 完整图形工作台。
- `SHA256SUMS.txt`：下载后校验文件是否完整。
