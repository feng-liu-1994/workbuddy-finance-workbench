# WorkBuddy 财务工作台 v2.3.0

这是一次以 FDE 财务治理视角完成的实用性升级：不仅发现异常，还要明确金额影响、责任人、截止时间、来源证据和关闭条件。同时整体放大字号与控件，减少财务人员长时间录入和复核时的视觉负担。

## 本版亮点

- **异常控制台**：跨对账、应收、应付、报销、税务和月结统一登记异常。
- **有证据才能关闭**：风险事项必须填写底稿、凭证号、复核记录或业务确认结论后才能闭环。
- **风险优先级**：结合风险等级、逾期、大额阈值和待业务确认状态计算可解释风险分数。
- **财务复核断言**：15 个业务模块新增发生、完整性、存在、准确性、截止、计价和权利义务等复核关注点。
- **更易读**：放大导航、正文、表单、按钮和关键数字，桌面与 390px 手机均完成回归。
- **可带走**：异常台账随 JSON 备份导出，也可单独导出 UTF-8 CSV。
- **完整保留**：资料上传、文件夹导入、拖放、搜索、筛选、置顶、引用、下载、待办、月结、审计和 25 个 AI 工作流均保留。
