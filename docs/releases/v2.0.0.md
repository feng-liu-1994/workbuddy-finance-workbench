# WorkBuddy 财务工作台 v2.0.0

首个完整开源版本，面向财务人员和 AI Agent。

## 亮点

- 11 个财务工作台模块，桌面与手机响应式适配。
- 22 个标准财务自动化场景和 3 个专业扩展场景。
- 工作流均包含输入、规则、7 步路径、输出、验收清单和人工复核边界。
- 资料库支持上传、文件夹导入、搜索、筛选、置顶、引用和下载。
- 月结证据清单、待办管理、字段字典、业务阈值和 JSON 备份。
- WorkBuddy、Codex、Claude Code 和通用 AI Agent Skill。
- macOS/Linux Shell、Windows PowerShell 和 DeepSeek Harness 安装脚本。
- 22 项自动化测试、GitHub Actions、公开脱敏扫描和虚构演示数据。

## 下载哪个文件

- `finance-workbench-agent-v2.0.0.zip`：WorkBuddy 或其他 AI Agent 用户。
- `dsh-finance-workbench-2.0.0.tgz`：DeepSeek Harness npm 插件包。
- `SHA256SUMS.txt`：下载后校验文件完整性。
- GitHub 自动生成的 Source code：开发者查看和二次开发。

完整新手安装步骤见仓库 README。

## 安全说明

发布物仅含通用源码、虚构示例和脱敏截图，不包含真实财务资料、个人身份信息、本机路径、Token、Cookie、密码或 API Key。付款、入账、纳税申报和重大判断仍必须由授权人员复核。
